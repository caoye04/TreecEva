目标: 求第5行执行后变量result的值

步骤1: 初始化变量
第1行: x = 10
→ 将变量x赋值为10
→ 当前状态: x=10
第2行: y = 20
→ 将变量y赋值为20
→ 当前状态: x=10, y=20
第3行: temp = x + y
→ 计算右侧表达式: x + y = 10 + 20 = 30
→ 结果: temp = 30
→ 当前状态: x=10, y=20, temp=30
第4行: result = temp * 2
→ 计算右侧表达式: temp * 2 = 30 * 2 = 60
→ 结果: result = 60
→ 当前状态: x=10, y=20, temp=30, result=60

步骤2: 最终计算
第5行: print(result)
→ 打印输出: result = 60
→ 当前状态: x=10, y=20, temp=30, result=60

最终答案: 60
